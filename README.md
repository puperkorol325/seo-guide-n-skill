# SEO skill для Claude, Codex, Cursor и других ИИ

<img width="2560" height="1440" alt="readme-banner" src="https://github.com/user-attachments/assets/7f6d8286-0db2-426f-9f4f-e84f28f099d4" />

Скилл позволяет разрабатывать или внедрять в уже готовые сайты комплекс мер по внутренней SEO оптимизации. ИИ сам следит за микроразметкой, показателями Web Core Vitals, правильностью и читаемостью текстов.

## Использование

1. Установите скилл в папку скиллов вашего ИИ агента.
   
   ```
   git clone https://github.com/puperkorol325/seo-guide-n-skill.git ~/.cursor/skills/
   ```
2. Используйте скилл
   ```
   /seo-geo-site
   ```
